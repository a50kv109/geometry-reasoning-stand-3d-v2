## 1. Состав репозитория и матрица воспроизведения

Для того чтобы внешняя система или независимый разработчик могли не просто изучить архитектуру, а **полностью воссоздать работающий стенд**, в репозитории зафиксированы все 6 ключевых компонентов воспроизводимости:

| № | Компонент | Расположение в репозитории | Назначение при воспроизведении |
| :-: | :--- | :--- | :--- |
| **1** | **Исходный код ядра и UI** | `/src/core/`, `/src/components/`, `/src/App.tsx`, `/index.html` | Полная математическая реализация, геометрическое ядро, реактивный 3D-клиент и Agent Console v0.1. |
| **2** | **Фиксация зависимостей** | `package.json`, `package-lock.json`, `bun.lock` | Точные версии пакетов с детерминированным графом (`npm ci` или `bun install`). |
| **3** | **Конфигурации сборки** | `vite.config.ts`, `tsconfig.json`, `src/index.css` | Идентичная компиляция Vite 6, TypeScript 5.8 (strict mode), Tailwind CSS 4. |
| **4** | **Тесты и контракты** | `/src/tests/` (12 сьютов, включая `golden_reference_snapshot.test.ts`) | Автоматический объективный критерий: «собралось и считает в точности так же». |
| **5** | **Паспорт воспроизведения** | `REPLICATION_MANIFEST.md`, `/docs/REPRODUCING.md`, `/docs/REPRODUCIBILITY_CHECKLIST.md` | Пошаговый ранбук выполнения шагов: `clone → install → test → dev → verify`. |
| **6** | **Эталонные снимки и скрипты** | `/examples/gatewayQuickstart.ts`, `/examples/agentQuickstart.ts`, `src/tests/golden_reference_snapshot.test.ts` | Аналитические эталоны ($T_d, C_1, V_s, \Omega$), проверка математической и визуальной эквивалентности. |

## 2. Системные требования и окружение

### Аппаратная платформа
- **Архитектура:** `x86_64` (amd64) или `arm64` (Apple Silicon M1/M2/M3/M4, Raspberry Pi 4/5).
- **Операционные системы:** Linux (Ubuntu 20.04+, Debian 11+, Fedora, RHEL), macOS (12+), Windows 10/11 (WSL2 или native PowerShell).
- **Память (RAM):** минимум 1 ГБ, рекомендуется 2 ГБ.
- **Дисковое пространство:** ~250 МБ (включая каталог `node_modules`).

### Поддерживаемые рантаймы
- **Node.js (рекомендуется):** `v18.0.0` – `v22.x.x` (протестировано на `v22.23.2`).
- **npm:** `v9.0.0` – `v10.x.x` (поставляется с Node.js).
- **Bun (альтернатива):** `v1.0.0` – `v1.2.x` (репозиторий содержит `bun.lock`).

### Отсутствие внешних секретов и сетевых зависимостей
- **Автономность:** 100% ядра, тестов, визуального стенда и агентного шлюза работают **полностью оффлайн**.
- Никаких API-ключей, баз данных или облачных токенов для работы не требуется.

## 3. Пошаговый регламент развёртывания (5 шагов)

### Шаг 1. Клонирование репозитория
```bash
git clone https://github.com/a50kv109/geometry-reasoning-stand-3d-v2.git
cd geometry-reasoning-stand-3d-v2
```

### Шаг 2. Детерминированная установка зависимостей
Для Node.js / npm:
```bash
npm ci
# или стандартная установка:
npm install
```
*Для Bun:* `bun install`

**Критерий успешности:** код возврата `0`, создан каталог `node_modules/`, содержащий `vite`, `react`, `tsx`, `typescript`, `@tailwindcss/vite`, `lucide-react`.

### Шаг 3. Запуск эталонных проверок и тестов
```bash
# 1. Запуск всех 12 тестовых сьютов (124+ утверждения)
npm run test:all

# 2. Запуск эталонного математического бенчмарка аналитических констант
npm run test:golden

# 3. Проверка типов TypeScript (строгий режим)
npm run lint
```
**Критерий успешности:** 
- Все тесты возвращают `ok`, статус `pass 124+`, `fail 0`.
- Линтер `tsc --noEmit` завершается без ошибок (код `0`).

### Шаг 4. Проверка работы агентных сценариев (Headless Execution)
```bash
# Демонстрация работы Agent Gateway v0.1:
# - Инспекция паспорта объекта (PGO-3D)
# - Инспекция паспорта симметрии (PSS-3D: T_d, порядок 24)
# - Проверка гипотезы агента (вектор доказательств)
# - Пертурбация геометрии и разрушение симметрии до C_1
# - Журнал экспериментов (Ledger)
npm run example:gateway

# Демонстрация оракула верификации гипотез
npm run example:agent

# Демонстрация динамической симуляции (LVG, DLVM, GDS, Temporal transitions)
npm run example:simulation
```

### Шаг 5. Сборка и локальный запуск визуального стенда
```bash
# Компиляция продакшен-бандла
npm run build

# Запуск интерактивного рабочего места (порт 3000)
npm run dev
```
Откройте браузер по адресу `http://localhost:3000`.

## 4. Эталонные результаты и аналитические константы

Каждая независимая среда воспроизведения обязана получить следующие **числовые значения с машинной точностью** ($|val - expected| < 10^{-10}$):

### А. Правильный тетраэдр, вписанный в единичную сферу $S^2(O, R=1.0)$
- **Координаты вершин:**
  - $A = (0, 0, 1)$
  - $B = (\frac{2\sqrt{2}}{3}, 0, -\frac{1}{3}) \approx (0.9428090416, 0, -0.3333333333)$
  - $C = (-\frac{\sqrt{2}}{3}, -\frac{\sqrt{6}}{3}, -\frac{1}{3}) \approx (-0.4714045208, -0.8164965809, -0.3333333333)$
  - $D = (-\frac{\sqrt{2}}{3}, \frac{\sqrt{6}}{3}, -\frac{1}{3}) \approx (-0.4714045208, 0.8164965809, -0.3333333333)$
- **Длина ребра:** $a = \frac{4}{\sqrt{6}} \approx 1.632993161855452$
- **Площадь грани:** $S_F = \frac{2\sqrt{3}}{3} \approx 1.1547005383792515$
- **Ориентированный объём:** $V_s = \frac{8\sqrt{3}}{27} \approx 0.5132002392796673$
- **Центроид:** $G = (0, 0, 0) \equiv O$
- **Телесный угол при каждой вершине:** $\Omega = 3 \arccos(\frac{1}{3}) - \pi \approx 0.551285598429942\text{ ср}$
- **Двугранный угол:** $\theta_{dih} = \arccos(\frac{1}{3}) \approx 70.528779^\circ$
- **Плоские углы граней:** $60.000000^\circ$ ($\frac{\pi}{3}$)
- **Определитель матрицы Грама:** $\det(\mathbf{G}) = 0.5000000000$

### Б. Симметрийная классификация (Группа Фёдорова)
- **Точечная группа симметрии:** $T_d$ (Шёнфлис) / $\bar{4}3m$ (Герман-Моген).
- **Порядок полной группы:** $24$ операции:
  - Тождественная операция: $E$ ($1$).
  - Повороты вокруг 4 осей $C_3$: по 2 операции на ось ($\pm 120^\circ$) = $8$.
  - Повороты вокруг 3 осей $C_2$: по 1 операции на ось ($180^\circ$) = $3$.
  - Отражения в 6 плоскостях $\sigma_d$: $6$.
  - Зеркально-поворотные операции $S_4$: $\pm 90^\circ$ вокруг 3 осей $C_2$ = $6$.
- **Собственная подгруппа вращений:** $T$ (порядок $12$).
- **Центральная инверсия:** **ОТСУТСТВУЕТ** (`inversionCenter.exists = false`, статус `REFUTED`).

### В. Деформированное состояние (Деградация симметрии)
- **Смещение вершины D:** $(\Delta x = +0.15, \Delta y = -0.10, \Delta z = +0.05)$ с проекцией на сферу $S^2$.
- **Точечная группа симметрии:** $C_1$ / $1$.
- **Порядок группы:** $1$ (сохраняется исключительно тождественная операция $E$).
- **Инвариантный топологический базис:** Сохраняются все 4 вершины, 6 рёбер, 4 грани, Эйлерова характеристика $\chi = 2$.

## 5. Визуальный чек-лист интерфейса (UI Verification)

При загрузке веб-приложения по адресу `http://localhost:3000`:
1. **Левая область (~65% ширины):**
   - 3D-сцена с единичной сферой $S^2$ и каркасом тетраэдра.
   - 4 цветных маркера вершин: $A$ (cyan), $B$ (emerald), $C$ (violet), $D$ (rose).
   - Вращение сцены мышью (OrbitControls) и перетаскивание любой вершины по поверхности сферы.
   - Кнопка HUD «🌐 Глобус углов D» вызывает локальный инспектор сферы направлений $S^2(v)$.
2. **Правая боковая панель (~35% ширины):**
   - **Координаты:** мгновенный пересчёт между декартовыми $(x,y,z)$ и сферическими $(\phi, \lambda)$.
   - **Инспектор LSM:** телесный угол $\Omega$, плоские углы, матрица Грама.
   - **Метрики:** длины всех 6 рёбер, площади 4 граней, ориентированный объём.
   - **Консоль агента (Agent Console v0.1):**
     - Вкладка `Пресеты`: 9 готовых команд для агента, включая пресет 9: *«Инспекция паспорта симметрии (T_d, 24 оп.)»*.
     - Вкладка `JSON Консоль`: поле ввода JSON-команды, кнопка отправки, форматированный ответ.
     - Вкладка `Паспорт`: карточка Паспорта объекта (PGO-3D) и Паспорта симметрии (PSS-3D).
     - Вкладка `Журнал`: история экспериментов с точными временными метками и вердиктами.
